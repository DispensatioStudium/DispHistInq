# DispHistInq - Site d'exploration de données historiques

## Description

Ce site web permet d'explorer et de visualiser les données relatives aux dispenses historiques de l'Inquisition. <br>

Voir : https://dispensatiostudium.github.io/DispHistInq/index.html

Les données appartiennent au projet **DispHistInq** porté par Jean-Pascal Gay, Éléna Guillemard et Mathis Gatelier.<br>
Le site a été réalisé par Théo Burnel.
